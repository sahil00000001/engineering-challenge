# Rendered examples

Generated by `npm run examples` from the fixtures in [`../fixtures`](../fixtures). Do not edit by hand.

A passing render writes `insight.png`. A render that fails visual validation keeps its
PNG as `insight.failed.png`, for diagnosis, so it can never be mistaken for a deliverable.
Content that is invalid, incomplete or changed since approval is not rendered at all.
Every case writes `report.json`.

Re-rendering on the same machine and Chromium build gives pixel-identical output, which
`tests/render.test.ts` checks. The committed PNGs were rendered on Windows. Font
anti-aliasing differs between operating systems, so PNG bytes rendered elsewhere can differ
even when layout and validation results are the same.
